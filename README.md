# QArt アートQRコード生成ツール

写真やイラストとQRコードを数学的に統合し、「スマホで100%読み取れる」デザインQRコードを自動生成するWebツールです。

## 🌟 特徴

* **100% スキャン保証**: 単に画像を重ねるのではなく、QArtアルゴリズムでQRコードのデータ構造（エラー訂正領域）自体を写真に化けさせるため、一発でスキャンが通ります。
* **プライバシー安全（完全ローカル処理）**: アップロードした画像が外部サーバーに送信されることは一切ありません。すべてお使いのブラウザ内で処理されます。
* **単一HTML完結**: サーバー不要で、GitHub Pagesやローカル環境でそのまま動作します。

## 🚀 使い方

1. 埋め込みたい **URL** を入力します。
2. お好みの **画像** をアップロード（ドラッグ＆ドロップ）します。
3. カラーモード（フルカラー / モノクロ）や解像度を選択します。
4. **「生成されたQRコードをダウンロード」** ボタンを押して保存します。

## 🛠️ 使用技術

* HTML5 / CSS3 / JavaScript (ES6)
* [QArt.js](https://github.com/75lb/qart) (QArt Algorithm Implementation)
